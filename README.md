# IRON ARENA — وب‌سایت باشگاه بدنسازی لاکچری

وب‌سایت کامل، فارسی و راست‌به‌چپ باشگاه بدنسازی **آیرون آرنا** برای آقایان و بانوان، با دو سانس صبح (۰۶:۰۰ تا ۱۲:۰۰) و عصر (۱۶:۰۰ تا ۲۳:۰۰).
سایت با **HTML، CSS و جاوااسکریپت خالص** ساخته شده است؛ بدون فریم‌ورک، بدون بک‌اند و بدون نیاز به build. همین فایل‌ها را روی GitHub Pages بگذارید تا سایت بالا بیاید.

**نسخهٔ زنده:** `https://rahmaniho.github.io/Gym/`

## 🚀 انتشار روی GitHub Pages

1. یک مخزن (Repository) در گیت‌هاب بسازید؛ مثلاً `Gym` یا `gym-website`.
2. همهٔ فایل‌ها را در **ریشهٔ** مخزن و روی شاخهٔ `main` قرار دهید:
   ```bash
   git add .
   git commit -m "انتشار سایت آیرون آرنا"
   git push origin main
   ```
3. در گیت‌هاب به **Settings ← Pages** بروید.
4. در بخش **Build and deployment** گزینهٔ **Source** را روی **Deploy from a branch** بگذارید.
5. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و **Save** را بزنید.
6. پس از یک تا دو دقیقه سایت در نشانی `https://USERNAME.github.io/REPO/` در دسترس است.

> همهٔ پیوندها نسبی‌اند، پس سایت با هر نام مخزنی بدون تغییر کار می‌کند. فایل `.nojekyll` هم پردازش Jekyll را غیرفعال می‌کند تا همهٔ فایل‌ها همان‌طور که هستند منتشر شوند.

### دامنهٔ اختصاصی (CNAME)

1. در ریشهٔ مخزن فایلی به نام `CNAME` (بدون پسوند) بسازید و فقط نام دامنه را در آن بنویسید:
   ```text
   ironarena.ir
   ```
2. در پنل DNS دامنه:
   - **برای دامنهٔ اصلی** (`ironarena.ir`) چهار رکورد `A` بسازید که به این نشانی‌ها اشاره کنند:
     `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153`
   - **برای زیردامنه** (`www`) یک رکورد `CNAME` بسازید که به `USERNAME.github.io` اشاره کند.
3. در **Settings ← Pages** دامنه را در بخش **Custom domain** وارد کنید و پس از صدور گواهی، گزینهٔ **Enforce HTTPS** را فعال کنید.
4. نشانی جدید را در متغیر `SITE_URL` فایل `tools/build.py` بنویسید و دستور `python3 tools/build.py` را اجرا کنید تا canonical، Open Graph، JSON-LD و sitemap به‌روز شوند.

### راه‌اندازی Formspree
1. در [formspree.io](https://formspree.io) حساب بسازید و یک فرم جدید ایجاد کنید.
2. نشانی‌ای مثل `https://formspree.io/f/abcdwxyz` دریافت می‌کنید؛ آن را جایگزین `YOUR_FORM_ID` کنید.

## ✍️ ویرایش محتوا

- **افزودن مقاله:** یک شیء جدید به ابتدای آرایهٔ `IA_BLOG` در `assets/js/blog-data.js` اضافه کنید (`id`, `title`, `excerpt`, `image`, `category`, `date`, `author`, `content`). زمان مطالعه، فهرست مطالب و مقالات مرتبط به‌طور خودکار ساخته می‌شوند. سپس `python3 tools/build.py` را اجرا کنید تا مقاله به sitemap اضافه شود.
- **قالب مشترک صفحات:** سربرگ، پابرگ، لودر و دکمه‌های شناور در `tools/partials/` قرار دارند. پس از ویرایش، دستور زیر آن‌ها را در همهٔ صفحات جای‌گذاری می‌کند (فقط به پایتون ۳ نیاز دارد):
  ```bash
  python3 tools/build.py
  ```
  خروجی این اسکریپت در مخزن ذخیره می‌شود، پس GitHub Pages به هیچ مرحلهٔ build نیازی ندارد.
- **تصاویر:** فایل‌های WebP را در `assets/img/` بگذارید (نسخهٔ کوچک با پسوند `-800` یا `-480`) و سپس `tools/build_lqip.sh` را اجرا کنید تا پیش‌نمایش‌های تار (blur-up) دوباره ساخته شوند.

## ⚡ عملکرد و دسترس‌پذیری

- فونت‌ها و کتابخانه‌ها به‌صورت محلی میزبانی می‌شوند؛ هیچ درخواستی به CDN خارجی ارسال نمی‌شود.
- jsPDF، html2canvas و Lottie فقط هنگام نیاز بارگذاری می‌شوند. نقشهٔ گوگل هم تا وقتی کاربر روی آن کلیک نکند بارگذاری نمی‌شود.
- تصاویر با `srcset`، `loading="lazy"` و پیش‌نمایش تار بارگذاری می‌شوند و تصویر اصلی هیرو از قبل preload می‌شود.
- ناوبری با صفحه‌کلید، پیوند «پرش به محتوا»، `aria-*`، کنتراست مناسب و احترام به `prefers-reduced-motion` رعایت شده است.
